PRIVACIDADE

Aviso de Privacidade

Este aviso explica, em linguagem direta, quais dados o sistema utiliza para operar o delivery e quais controles estão disponíveis ao cliente.

1. Quem trata os dados

A pizzaria que opera este delivery é responsável pelos dados utilizados no atendimento, preparo, entrega e histórico dos pedidos. A GuiaSys Studio fornece a tecnologia do sistema.

2. Dados utilizados

O sistema pode utilizar nome, e-mail de autenticação, telefone, endereços de entrega, preferências, favoritos, dados dos pedidos e informações necessárias para validação cadastral.

O CPF é solicitado para identificação única. Após a validação, o número bruto não é mantido no cadastro operacional: o servidor conserva somente informações técnicas protegidas necessárias para reconhecer que o documento já foi validado e evitar duplicidade.

3. Finalidades

Os dados são utilizados para criar e proteger a conta, registrar pedidos, realizar entrega ou retirada, permitir contato sobre o pedido, emitir comprovantes do sistema, evitar cadastros duplicados, prestar suporte e manter registros operacionais e financeiros.

4. Acesso por funcionários

O sistema aplica controle de acesso por função. Perfis que não precisam de dados pessoais recebem somente informações operacionais, como itens, valores e andamento do pedido. Nome, telefone e endereço do pedido são carregados apenas para perfis autorizados que precisam dessas informações para atendimento, impressão ou entrega.

A ficha cadastral do cliente e seus endereços pessoais não ficam disponíveis para consulta direta no painel administrativo.

5. Compartilhamentos necessários

Serviços técnicos usados para autenticação, banco de dados, hospedagem e consulta de CEP podem processar informações estritamente necessárias ao funcionamento. Dados de entrega também podem ser usados pela equipe responsável por cumprir o pedido.

6. Retenção

Dados da conta podem ser excluídos pelo próprio cliente. Registros transacionais de pedidos já realizados podem ser preservados sem os dados de contato quando isso for necessário para histórico operacional, prevenção de fraude, contabilidade ou cumprimento de obrigação legal.

7. Seus controles

Em Minha Conta → Privacidade e dados, o cliente pode baixar uma cópia dos dados disponíveis em sua conta e solicitar a exclusão da conta. Também pode corrigir nome, telefone e endereços diretamente no sistema.

8. Segurança

Dados sensíveis são separados dos registros operacionais, permissões seguem o princípio do menor privilégio e operações administrativas críticas são executadas no servidor, não diretamente pelo navegador.

9. Contato

Para dúvidas sobre privacidade, correção de dados ou solicitações que não possam ser concluídas pela área Minha Conta, utilize os canais de contato exibidos pela pizzaria no próprio delivery.
