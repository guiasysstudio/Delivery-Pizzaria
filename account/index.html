Como seus dados são usados

Nome, telefone e endereços são usados para atendimento e entrega. O CPF é validado para identificação única, mas o sistema não mantém o número bruto após a validação; ele fica representado por dados técnicos protegidos no servidor.

Dados pessoais do cadastro não ficam disponíveis na ficha administrativa. Quando um pedido exige contato ou entrega, somente perfis operacionais autorizados podem carregar esses dados.

Excluir minha conta

A exclusão remove perfil, endereços, favoritos, cupons pessoais e dados de identificação. Registros financeiros de pedidos já realizados podem ser preservados sem seus dados de contato, quando necessários para histórico operacional, contábil ou cumprimento de obrigação legal.
